- **مرز کار:** این پیش‌نمایش مربوط به فهرست منابع داخل گفت‌وگو است، نه تأیید تمام رابط‌های جست‌وجوی مستقل دیگر. پیش‌نمایش آنلاین خودکار عمداً اضافه نشده است.

## ۲. دروازه‌های اجباری پیش از هر ساخت/نصب نسخه ۰.۳.۴
۱. سبز شدن GitHub Actions شامل خط مبنا، `dart format`، `flutter analyze`، آزمون‌ها و کامپایل Android **بدون APK** برای آخرین Commit اجرایی؛ نتیجه و SHA باید در این سند ثبت شود.
۲. از وضعیت واقعی تبلت و برنامه `0.3.3+6` یک پشتیبان **تازه، قابل‌دسترسی و قابل‌بازیابی** تهیه شود؛ به‌ویژه تاریخچه چت، حافظه پروژه، تنظیمات، شناسه منابع و مجوزهای SAF. مطابق مسیر رسمی موجود؛ بدون حذف Data/Cache.
۳. حضور و مسیر دسترسی مدل Qwen3.5 4B GGUF Q4_K_M و ZIM تصویری فارسی تقریبی ۱۳٫۷۸ گیگابایت پیش و پس از ارتقا جداگانه ثبت شود. رمز، توکن، کلید امضا و محتوای خصوصی در GitHub قرار نگیرد.
۴. بستهٔ تازه باید همان `applicationId=ir.pardis.ai.pala.f1diag2` و **گواهی امضای مالک** را داشته باشد؛ از fallback امضای Debug جلوگیری شود. برای ارتقا از `0.3.3+6` شماره ساخت جدید باید **بزرگ‌تر از ۶** باشد (مثلاً `0.3.4+7` فقط پس از تصویب فرایند انتشار).
۵. قبل از نصب، روش بازگشت آزمایش/مستند شود: Android معمولاً downgrade مستقیم `versionCode` را مجاز نمی‌داند؛ حفظ APK قبلی به‌تنهایی برگشت درجا را تضمین نمی‌کند. مسیر رسمی با همان امضا، نسخه سازگارِ بالاتر، پشتیبان و حفظ داده‌ها لازم است.
۶. نصب فقط به‌شکل **Update روی برنامه موجود**؛ اگر نصب‌گر Uninstall، Clear Data یا امضای ناسازگار خواست، فوراً متوقف شود. ساخت Candidateهای موازی و APKهای مکرر مجاز نیست.

## ۳. پروتکل کوتاه آزمون واقعی Galaxy Tab S10 Ultra
- اینترنت را خاموش کنید؛ **ZIM تصویری فارسی واقعی** را با همان مجوز و پوشه قبلی در دسترس نگه دارید و Qwen3.5 4B همان فایل را بارگذاری کنید.
- در مقاله‌ای که **واقعاً دارای عکس مربوط به موضوع است** پرسشی مثل «آفت‌های درخت گلابی چیست؟» بپرسید (اگر خود مقاله عکس مرتبط ندارد، از مقاله تصویردارِ تأییدشده استفاده شود؛ تصویر نامربوط هرگز قبولی نیست).
- باید متن پاسخ، استناد به همان منبع، **حداکثر دو تصویر ابتدا** با کپشن و برچسب منشأ آفلاین و «نمایش بقیه عکس‌ها» برای باقی نامزدهای واقعاً موجود دیده شود؛ تصویرهای بدون منبع/اینترنتی مجاز نیستند.
- فهرست کامل منابع پاسخ را باز کنید: **پیش‌نمایش بندانگشتی** فقط برای مقالات محلی دارای عکس، تا سقف چهار منبع؛ لمس تصویر برای بزرگ‌نمایی و لمس منبع برای مقاله باید عمل کند.
- نبود عکس، مجوز لغوشده، چند منبع متوالی بدون عکس و تصویر تکراری نباید برنامه را هنگ یا پاسخ متنی را مخدوش کنند؛ اینترنت یا دانلود خودکار نباید لازم شود.
- در پایان، گفت‌وگوهای قدیمی، حافظه پروژه، تنظیمات، فایل GGUF، اجازه فایل ZIM و خواندن PDF را بررسی کنید؛ هرگونه از دست رفتن داده **BLOCKER** است.
- برای اندازه‌گیری عملکرد، مدل/Context/پرسش و وضعیت پس‌زمینه را ثابت نگه دارید؛ زمان بارگذاری/اولین توکن و حافظهٔ PSS/RSS را ثبت و با خط مبنای `0.3.3` مقایسه کنید. از تصویر اندروید: میانگین RAM برنامه **۲٫۰GB** و بیشینهٔ ثبت‌شده **۳٫۱GB**؛ این فقط مشاهده مقدماتی است، نه بنچمارک کنترل‌شده.
