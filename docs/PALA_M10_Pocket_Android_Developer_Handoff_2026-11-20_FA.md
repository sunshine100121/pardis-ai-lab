# PALA — مأموریت ۱۰: تحویل توسعه موتور صوت Pocket Farsi v2

تاریخ: ۲۰ نوامبر ۲۰۲۶
شاخه جداگانه: \`pala/pocket-farsi-v2-android-proto-2026-11-20\`
مالک برنامه موجود: نسخه \`0.3.3+6\` روی Tab S10 Ultra
**وضعیت ثبت اولیه: توسعه ~۹۵٪؛ تکمیل تحویل مشروط به تأیید نهایی APK و انتخاب دقیق کتابخانه native ONNX.**

## هدف
موتور تولید صدای فارسی واقعی و طبیعی، آفلاین، بدون سرویس پولی، از Pocket Farsi v2؛ حفظ Gyro، Qwen، اسناد و SAF/ZIM موجود.

## چیزهایی که واقعاً پیاده‌سازی شده‌اند
- اجرای بومی G2P، ONNX FlowLM و Mimi، خروجی PCM16 24kHz؛ فقط کامپایل و تست‌های پل صوتی از GitHub تأیید شده‌اند، نه کیفیت واقعی PCM.
- تقسیم ورودی بلند به قطعات بدون حذف متن، و واج‌سازی هر قطعه در پنجره‌های حداکثر ۳۰ واژه.
- توقف، ادامه و لغو؛ لغو تولید native در حلقه FlowLM و لغو پخش.
- نگهداری نشست‌های ONNX و voice cache در یک نوبت خواندن، آزادسازی بعد از پایان؛ استفاده از FloatBuffer مستقیم برای KV های حجیم و کنترل کیفیت خروجی با حداکثر دو تلاش مجدد.
- پشتیبانی اولیه حروف فارسی/عربی، اعداد و برخی اصطلاحات لاتین.
- ZIP مدل فقط در بخش بسته «آزمایشی/پیشرفته» با انتخاب صریح مالک و فایل‌های قانونی؛ بدون دانلود یا انتخاب صدای خودکار.
- دکمه شنیدن نمونه، نمایش RTF، ورود اختیاری Pocket به Conversation فقط پس از شنیدن نمونه موفق، و «بازگشت به صدای قبلی» بدون دستکاری HayaiTTS/Gyro.
- اسکریپت بسته‌ساز آفلاین \`scripts/prepare_pocket_farsi_v2_bundle.py\`؛ ورود امن staging و جلوگیری از overwrite.
- آزمون با \`tokenizer_ph.model\` واقعی: ۱۵ نمونه با کتابخانه اصلی SentencePiece در اجرای \`44721236800\` مطابق شدند. این **تطبیق الگوریتم/fixture** است، نه اجرای کد Kotlin با وزن‌ها روی تبلت.

## ایمنی بسته Android
- نسخه نصب‌شده \`0.3.3+6\` یا کلید signing آن تغییر نکرده است؛ main و شاخه ادغام نیز دست‌نخورده.
- APK تشخیصی فقط با شناسه مجزای \`ir.pardis.ai.pala.f1diag2.pockettest\` قابل ساخت است؛ نسخه تست از نظر داده و مجوز مستقل از PALA اصلی است.
- **هنوز APK نهایی تحویل نشده است**؛ پس از موفقیت Gradle و تطبیق SHA کتابخانه \`libonnxruntime.so\` با AAR Microsoft 1.31.1، شماره run و checksum درج شود. تضاد کتابخانه shared Sherpa/ONNX Runtime در پیشرفت CI مشاهده و برای بسته آزمون guard اضافه شده است.
- ZIP حدود ۴۹۱MB شامل فایل‌های اصلی مدل، \`tokenizer_ph.model\` و WAV مجاز؛ وزن‌ها نباید در APK یا Git قرار گیرند. مجوز مدل CC-BY-NC-4.0 است.
- صدای مرجع WAV باید ۲۴kHz، mono، PCM16 و ۰٫۵ تا ۵ ثانیه باشد؛ فقط از صدایی استفاده شود که مالک اجازه استفاده دارد.

## آزمایش عملی جداگانه — جزء درصد توسعه من نیست
۱. پس از تحویل موفق APK تشخیصی و بسته ZIP مجاز، آن را **کنار** پالا نصب کنید؛ جایگزین نسخه اصلی نیست.
۲. بخش تنظیمات صدا ← Pocket آزمایشی و پیشرفته ← انتخاب ZIP ← بررسی بسته.
۳. «شنیدن نمونه» با اتصال اینترنت خاموش؛ RTF و مدت نمونه یادداشت شود؛ مقایسه کیفی با Gyro و Pocket Surface.
۴. فقط اگر نتیجه شنیداری قابل‌قبول بود، «استفاده آزمایشی در مکالمه» را فعال کنید؛ ۱۰ درخواست متوالی، شامل دما/رطوبت/اعداد فارسی و متن بلند، آزمایش شود.
۵. در صورت تأخیر یا مشکل، انتخاب Pocket را لغو کنید؛ برای حذف کامل APK تشخیصی کافی است همان برنامه جدا را حذف کنید، پالا اصلی بدون تغییر می‌ماند.
۶. RAM واقعی و RTF در کنار Qwen3.5 4B بررسی شود؛ چون APK جدا مدل Qwen قبلی را به‌طور خودکار منتقل نمی‌کند، آزمون همزمان Qwen باید پس از تأیید بخش Pocket در محیط ادغام ایمن انجام شود.

## شرایط صداقت گزارش
- فقط موفقیت GitHub Flutter tests و Kotlin compile، اثبات تولید واقعی صدای طبیعی، تعادل حافظه، و صحت همه واژه‌ها نیست.
- درصد ۱۰۰٪ توسعه صرفاً با تحویل بسته تست قابل‌نصب و گزارش build/identity/نصب‌پذیریِ بررسی‌شده قابل ادعاست؛ **پذیرش کیفیت روی تبلت جدا است**.
- هر خطای native/runtime بعد از آزمایش عملی، با حفظ rollback و بدون تغییر صدای فعال اصلاح شود.

## آزمایش مستقل درخواست‌شده پس از نصب PALA 0.3.4 — ۲۱ نوامبر ۲۰۲۶
- مالک پس از خطاهای انتخاب Vosk و درخواست بسته Android/STT و بررسی Shenava خواست **Pocket Farsi v2 را عملاً آزمایش کند**، نه صرف دیدن تنظیمات دکوری. صدای HayaiTTS/Jiro، نصب PALA 0.3.4+7، داده‌های تبلت و مدل واقعی Qwen3.5 9B باید حفظ شوند.
- آخرین شاخه آزمایش Pocket `pala/pocket-farsi-v2-android-proto-2026-11-20` همچنان کاملاً جدا از نسخه PALA 0.3.4 است. خروجی آزمون‌ها برای tokenizer/Flutter/Kotlin **جایگزین تولید واقعی صدا نیستند**. مدل ONNX/توکنایزر و WAV مرجع در APK گنجانده نشده‌اند؛ تست واقعی نیازمند بستهٔ ۱۴ فایلی مجاز (تقریباً ۴۹۱MB) و صدای مرجع PCM16 mono 24kHz است. بسته‌ساز محلی `scripts/prepare_pocket_farsi_v2_bundle.py` از قبل وجود دارد و وزن‌ها را در Git یا APK منتشر نمی‌کند.
- بررسی GitHub Actions: سه اجرای قبلی تشخیص مستقل `44720527593`، `44722326595` و `44726380651` همگی FAIL و **بدون Artifact منتشرشده** بودند. در آخرین اجرا `flutter build apk --debug --target-platform android-arm64` توانست APK بسازد، اما کنترل بعدی `Wrong bundled ORT version; refuse to ship APK` آن را متوقف کرد؛ کتابخانه `libonnxruntime.so` بسته با نسخه Microsoft ONNX Runtime Android `1.31.1` منطبق نبوده است. کنترل ایمنی نباید حذف شود و هیچ APK قدیمیِ نامعتبر توصیه نشود.
- اصلاح محدود تشخیصی و بدون تغییر برنامه نصب‌شده: در `scripts/prepare_pocket_diagnostic_ort.py` فایل واقعی Microsoft 1.31.1 از AAR موجود Gradle شناسایی و hash می‌شود، و فقط کپی قدیمی Sherpa `libonnxruntime.so` در **cache موقت runner** کنار گذاشته می‌شود؛ منابع و کلید امضای PALA اصلی تغییر نمی‌کنند. Workflow `.github/workflows/pala-pocket-test-apk.yml` نیز به‌جای جست‌وجوی نادرست در Gradle transform cache، SHA256 باینری داخل APK را با SHA256 باینری **درون AAR Microsoft 1.31.1** مقایسه می‌کند. شرط شناسه مستقل `ir.pardis.ai.pala.f1diag2.pockettest` و ممنوعیت مدل/صدای مرجع داخل APK حفظ شده است.
- **یک اجرای تشخیصی جدید** با Run `44924812497` و Commit `c24fa7842d104c650d197df56fb73574943c5319` شروع شد. نتیجه هنوز در زمان ثبت این Checkpoint **in_progress** است؛ نباید PASS یا فایل قابل دریافت ادعا شود. اگر خطا داد از اجرای‌های رفت‌وبرگشتی پرهیز و علت بررسی شود.
- پس از تحویل یک APK مستقل تأییدشده و تهیه بسته رسمی مجاز، آزمایش واقعی Pocket روی Galaxy Tab S10 Ultra باید جداگانه (بدون حذف/Update پالا اصلی و بدون تغییر Gyro) شامل تولید نمونه، RTF، RAM، پخش فارسی و مقایسه شنیداری باشد. تا آن زمان `POCKET_ANDROID_AUDIO=NOT_VERIFIED` و `M10_ACCEPTED=NO`.

## بسته‌ساز شخصی Pocket برای Surface و آخرین وضعیت ساخت تشخیصی — ۲۱ نوامبر ۲۰۲۶
- اسکریپت تازه `scripts/prepare_pocket_farsi_v2_personal_test.py` در Commit `1ee377b18b691b571bec6b18361e17383217732b` ثبت شد و با `python -m py_compile` روی نمونه محلی از همان سورس از نظر نحو بررسی شده است؛ **اجرای دانلود ۱۲ مدل/توکنایزر واقعی در Surface یا ساخت ZIP واقعی هنوز انجام نشده است**.
- کارکرد اسکریپت: در Python 3.12 موجود Surface و با `huggingface_hub`، فایل‌های ONNX رسمی از `Nimaone/pocket-tts-farsi-v2-onnx` و `tokenizer_ph.model` و نمونه WAV مرجع از `mehdi-hf/pocket-tts-farsi-v2` را در cache دانلود می‌کند (یا WAV مجاز مالک با `--voice`)، صدا را به mono PCM16 24kHz با طول ۰٫۵ تا ۵ ثانیه تبدیل و با بسته‌ساز موجود `scripts/prepare_pocket_farsi_v2_bundle.py` و پس از بررسی ساختار/حجم/فضای آزاد، یک ZIP محلی می‌سازد. از بازنویسی خروجی موجود جلوگیری می‌کند؛ هیچ APK/مدل نصبی/صدا را جایگزین نمی‌کند و فایل‌های ۴۹۱MB یا WAV خصوصی را در GitHub قرار نمی‌دهد. **نتیجه دانلود و صحت اجرای مدل واقعی هنوز NOT VERIFIED**.
- در اجرای تشخیصی `44924812497` مرحله Kotlin/host و مرحله `Stage verified Microsoft ORT only in disposable diagnostic runner` **PASS** مشاهده شدند؛ هنگام این ثبت مرحله ساخت ARM64 debug APK `in_progress` و Verify/Upload هنوز `pending` بودند. هیچ لینک APK ساخته‌شده نهایی تا تأیید همه مراحل ارائه نشود. پکیج آزمایش باید شناسه مجزای `ir.pardis.ai.pala.f1diag2.pockettest` داشته باشد؛ فایل مدل از داخل آن منتشر نشود.
- کارهای بعد تنها پس از تحقق دو پیش‌شرط: (۱) خروجی Artifact APK با کنترل ORT/شناسه/امضا PASS، (۲) ZIP مدل واقعی از منابع رسمی و مرجع مجاز روی رایانه مالک. آنگاه نصب APK مجزا و آزمون شنیداری روی تبلت با اینترنت خاموش، اندازه‌گیری RAM/RTF و مقایسه با Gyro. **نسخه اصلی پالا، Qwen3.5 9B و Gyro هیچ تغییری نکرده‌اند.**
