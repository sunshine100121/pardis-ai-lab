# PALA — مأموریت ۱۰: تحویل توسعه موتور صوت Pocket Farsi v2

تاریخ: ۲۰ نوامبر ۲۰۲۶
شاخه جداگانه: \`pala/pocket-farsi-v2-android-proto-2026-11-20\`
مالک برنامه موجود: نسخه \`0.3.3+6\` روی Tab S10 Ultra
**وضعیت ثبت اولیه: توسعه ~۹۵٪؛ تکمیل تحویل مشروط به تأیید نهایی APK و انتخاب دقیق کتابخانه native ONNX.**

## هدف
موتور تولید صدای فارسی واقعی و طبیعی، آفلاین، بدون سرویس پولی، از Pocket Farsi v2؛ حفظ Gyro، Qwen، اسناد و SAF/ZIM موجود.

## چیزهایی که واقعاً پیاده‌سازی شده‌اند
- اجرای بومی G2P، ONNX FlowLM و Mimi، خروجی PCM16 24kHz؛ فقط کامپایل و تست‌های پل صوتی از GitHub تأیید شده‌اند، نه کیفیت واقعی PCM.
- تقسیم ورودی بلند به قطعات بدون حذف متن، و واج‌سازی هر قطعه در پنجره‌های حداکثر ۳۰ واژه.
- توقف، ادامه و لغو؛ لغو تولید native در حلقه FlowLM و لغو پخش.
- نگهداری نشست‌های ONNX و voice cache در یک نوبت خواندن، آزادسازی بعد از پایان؛ استفاده از FloatBuffer مستقیم برای KV های حجیم و کنترل کیفیت خروجی با حداکثر دو تلاش مجدد.
- پشتیبانی اولیه حروف فارسی/عربی، اعداد و برخی اصطلاحات لاتین.
- ZIP مدل فقط در بخش بسته «آزمایشی/پیشرفته» با انتخاب صریح مالک و فایل‌های قانونی؛ بدون دانلود یا انتخاب صدای خودکار.
- دکمه شنیدن نمونه، نمایش RTF، ورود اختیاری Pocket به Conversation فقط پس از شنیدن نمونه موفق، و «بازگشت به صدای قبلی» بدون دستکاری HayaiTTS/Gyro.
- اسکریپت بسته‌ساز آفلاین \`scripts/prepare_pocket_farsi_v2_bundle.py\`؛ ورود امن staging و جلوگیری از overwrite.
- آزمون با \`tokenizer_ph.model\` واقعی: ۱۵ نمونه با کتابخانه اصلی SentencePiece در اجرای \`44721236800\` مطابق شدند. این **تطبیق الگوریتم/fixture** است، نه اجرای کد Kotlin با وزن‌ها روی تبلت.

## ایمنی بسته Android
- نسخه نصب‌شده \`0.3.3+6\` یا کلید signing آن تغییر نکرده است؛ main و شاخه ادغام نیز دست‌نخورده.
- APK تشخیصی فقط با شناسه مجزای \`ir.pardis.ai.pala.f1diag2.pockettest\` قابل ساخت است؛ نسخه تست از نظر داده و مجوز مستقل از PALA اصلی است.
- **هنوز APK نهایی تحویل نشده است**؛ پس از موفقیت Gradle و تطبیق SHA کتابخانه \`libonnxruntime.so\` با AAR Microsoft 1.31.1، شماره run و checksum درج شود. تضاد کتابخانه shared Sherpa/ONNX Runtime در پیشرفت CI مشاهده و برای بسته آزمون guard اضافه شده است.
- ZIP حدود ۴۹۱MB شامل فایل‌های اصلی مدل، \`tokenizer_ph.model\` و WAV مجاز؛ وزن‌ها نباید در APK یا Git قرار گیرند. مجوز مدل CC-BY-NC-4.0 است.
- صدای مرجع WAV باید ۲۴kHz، mono، PCM16 و ۰٫۵ تا ۵ ثانیه باشد؛ فقط از صدایی استفاده شود که مالک اجازه استفاده دارد.

## آزمایش عملی جداگانه — جزء درصد توسعه من نیست
۱. پس از تحویل موفق APK تشخیصی و بسته ZIP مجاز، آن را **کنار** پالا نصب کنید؛ جایگزین نسخه اصلی نیست.
۲. بخش تنظیمات صدا ← Pocket آزمایشی و پیشرفته ← انتخاب ZIP ← بررسی بسته.
۳. «شنیدن نمونه» با اتصال اینترنت خاموش؛ RTF و مدت نمونه یادداشت شود؛ مقایسه کیفی با Gyro و Pocket Surface.
۴. فقط اگر نتیجه شنیداری قابل‌قبول بود، «استفاده آزمایشی در مکالمه» را فعال کنید؛ ۱۰ درخواست متوالی، شامل دما/رطوبت/اعداد فارسی و متن بلند، آزمایش شود.
۵. در صورت تأخیر یا مشکل، انتخاب Pocket را لغو کنید؛ برای حذف کامل APK تشخیصی کافی است همان برنامه جدا را حذف کنید، پالا اصلی بدون تغییر می‌ماند.
۶. RAM واقعی و RTF در کنار Qwen3.5 4B بررسی شود؛ چون APK جدا مدل Qwen قبلی را به‌طور خودکار منتقل نمی‌کند، آزمون همزمان Qwen باید پس از تأیید بخش Pocket در محیط ادغام ایمن انجام شود.
