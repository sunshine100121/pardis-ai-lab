- هیچ تستی بدون مشاهده نتیجه واقعی PASS محسوب نشود. اگر GitHub Actions قابل مشاهده نبود، نتیجه **NOT VERIFIED** است.

- سنجش سرعت، RAM، مجوزهای SAF، عدم افشای منابع بین پروژه‌ها، نسخه واقعی تبلت و ذخیره اطلاعات پس از ارتقا هنوز آزمون واقعی دستگاه می‌خواهد.
- سازگاری داده‌های قدیمی نباید به خاطر توسعه نمایه به خطر بیفتد.
- پس از نتیجه CI، خطاهای واقعی با Commit کوچک و آزمون متمرکز اصلاح شوند؛ از تکرار ساخت یا CI بی‌دلیل پرهیز شود.
