# PALA 0.3.4 — تحقیق موتورهای گفتار فارسی و گسترش موتورهای آفلاین

**تاریخ:** ۲۰ نوامبر ۲۰۲۶. **شاخه:** `pala/integrated-034-2026-11-17`.

## دامنه تحقیق و احتیاط
- «پرمصرف‌ترین موتور در همه اپلیکیشن‌های ایران» را نمی‌توان از صفحات معرفی خدمات یا تعداد ستاره GitHub استنتاج کرد. آمار باز و حسابرسی‌شده سهم استفاده در اپ‌های ایرانی یافت نشده است؛ نتیجه این سند **ارزیابی کاربرد و امکان‌پذیری فنی** است، نه رتبه‌بندی سهم بازار.
- معیارهای اجرایی: فارسی واقعی؛ آفلاین کامل؛ بدون اشتراک/API؛ Android ARM64 روی Tab S10 Ultra با RAM 12 GB؛ استقلال STT و TTS؛ انتخاب/حذف توسط مالک؛ عدم بارگیری اجباری؛ عدم دست‌زدن به Qwen GGUF/ZIM و داده‌های PALA.
- STT آفلاین شناخته‌شده: Vosk (مدل‌های کوچک و بزرگ)، خانواده ایرانی Shenava/Rizeh/Koochik ONNX بر sherpa-onnx. Whisper فارسی پیش‌تر روی تبلت نتیجه ضعیف داشته و Android Offline STT روی تبلت فارسی را پشتیبانی نکرده است؛ هیچ‌کدام جایگزین خودکار نشوند.
- TTS: Piper/VITS فارسی (fa_IR-gyro-medium، fa_IR-amir-medium، fa_IR-ganji-medium، ...)، موتور سیستم Android HayaiTTS، AvaCore و eSpeak در صورت نصب؛ بعضی سیستم‌ها از eSpeak NG داخلی استفاده می‌کنند، بعضی صدای عصبی با sherpa-onnx.
- فارس‌آوا، نویسا و سایر APIهای تشخیص گفتار و تولید صدای فارسیِ ابری ممکن است در محصولات ایرانی استفاده شوند، اما بدون اینترنت مستقل نیستند. این مأموریت هیچ سرویس خارجی را فعال نمی‌کند.

## پیاده‌سازی این شاخه
۱. **Vosk** حفظ و پشتیبانی مدل‌های متعدد ادامه یافته است. مسیر موجود Android TTS از قبل به طور پویا موتور نصب‌شده مانند HayaiTTS/AvaCore را شناسایی می‌کند؛ اما **نصب بودن هیچ‌یک روی تبلت از GitHub قابل اثبات نیست**.
۲. **Shenava / NeMo-CTC** به عنوان آداپتور واقعی `sherpa-ctc` روی sherpa_onnx موجود: کاربر ZIP/TAR.BZ2 سازگار را وارد می‌کند؛ در پوشه اختصاصی ذخیره می‌شود؛ محتوای صوتی از میکروفون 16 kHz به recognizer در worker isolate می‌رود، نتیجه نهایی غیرخالی به Qwen می‌رسد. متن خروجی ممکن است برای نشانه‌گذاری/اعداد نیازمند postprocessing باشد؛ کیفیت باید آزمایش شود.
۳. **Piper / VITS** به عنوان آداپتور واقعی `tts:piper` روی sherpa_onnx موجود: بسته مدل با `tokens.txt` و `espeak-ng-data/phontab` بررسی می‌شود؛ مدل در worker جداگانه PCM تولید می‌کند و از VoiceAudioChannel پخش می‌شود. صدای فعال از TTS مستقل از انتخاب STT است.
۴. بسته‌ها فقط با اقدام مالک وارد می‌شوند، با حد حجم و مقابله با مسیرهای ناامن؛ فایل اصلی مدل‌ها و اطلاعات قبلی حذف یا جابه‌جا نمی‌شود. SHA256 برای شناسه محتوا محاسبه می‌شود **ولی بدون هش مورد اعتمادِ ناشر اصالت دانلود را اثبات نمی‌کند**. برای انتشار عمومی باید مجوز هر مدل و داده آموزشی آن جداگانه بازبینی شود.
۵. مدل‌هایی با فرمت دیگر، از جمله Shenava RNNT (encoder/decoder/joiner)، Pocket Farsi، موتور TTS مستقل و غیر Android با پروتکل متفاوت، **به آداپتور جدا نیاز دارند**. صرف نام‌بردن از موتور به معنی پشتیبانی نیست.

- برنامه اصلی 0.3.3+6، شاخه main، امضا، داده‌های کاربر، Qwen/ZIM و سامانه HA/PVM دست‌نخورده‌اند.

## اصلاح اولویت مالک — ۲۰ نوامبر ۲۰۲۶: TTS طبیعی در سطح Pocket Farsi v2

**تصمیم قطعی و اصلاح برداشت قبلی:** هدف مأموریت ۱۰ افزودن تعداد زیاد موتور TTS یا صدای مصنوعیِ دیگر نیست؛ هدف صدای فارسی طبیعی، روان، انسانی و در عمل **بهتر از صدای Gyro فعلی در HayaiTTS** است. مالک HayaiTTS/Gyro را همین حالا روی Galaxy Tab S10 Ultra دارد و آن را از Piper بهتر ارزیابی می‌کند. بنابراین **Piper/VITS صرفاً آداپتور سازگاری اختیاری است، نه هدف نهایی کیفیت، نه پیش‌فرض پیشنهادی فارسی، و نه مدرک قبولی مأموریت ۱۰.**

**معیار صوتی مرجع:** Pocket Farsi v2 که مالک قبلاً روی Surface Pro 3 آزمایش و کیفیت طبیعی آن را پسندیده است. اعداد تاریخیِ گزارش‌شده برای اجرای Surface، تقریبی‌اند: بارگذاری ~۲٫۱۸ ثانیه، تولید ~۴٫۴۴ ثانیه، RTF ~۰٫۷۸ و حداکثر RAM فرایند ~۱٫۱۹ GiB. این اعداد معیار اولیه مقایسه‌اند و **نشانه عملکرد روی تبلت اندرویدی نیستند**.

### یافته فنی جدید: بسته آماده ONNX فارسی
- [Nimaone/pocket-tts-farsi-v2-onnx](https://huggingface.co/Nimaone/pocket-tts-farsi-v2-onnx) همان خانواده وزن‌های اصلی `mehdi-hf/pocket-tts-farsi-v2` را به ONNX تبدیل کرده و بسته چندگرافی آفلاین فراهم می‌کند. در [منبع اجرای ONNX](https://github.com/nimaone/persian_tts) حجم بسته حدود ۴۶۹ مگابایت و اجرای desktop با ONNX Runtime بدون PyTorch گزارش شده است. **این ادعا به معنی آن نیست که Android آماده و آزمایش‌شده است.**
- بسته شامل `flow_lm_step.onnx`، `mimi_encoder.onnx`، `mimi_decoder_step_kv.onnx`، `g2p_encoder.onnx`، `g2p_decoder.onnx` و نیز `weights.npz`، `decode_state_init.npz` و `manifest.json` است. تبدیل فارسی به واج (G2P)، هماهنگی چندگراف، وضعیت decoder/FlowLM، نمونه‌برداری و قطعه‌بندی باید عیناً پیاده‌سازی شود؛ **نمی‌توان Pocket Farsi v2 را به آداپتور Piper/VITS یا یک فراخوانی عمومی ONNX سپرد.**
- مدل اصلی و تبدیل ONNX آن تحت **CC-BY-NC-4.0** منتشر شده‌اند؛ برای بررسی و استفاده غیرتجاریِ شخصی می‌توان شرایط مجوز را رعایت کرد، ولی نباید وزن‌ها را بدون بررسی حقوق بازتوزیع داخل APK عمومی منتشر کرد.
- یک موتور سیستمی مستقل Android برای Pocket TTS نیز وجود دارد: [PocketTTS-Android-Engine](https://github.com/The-unknown-Shadowman/PocketTTS-Android-Engine). نسخه‌های عمومی آن فعلاً مدل‌های انگلیسی، آلمانی، ایتالیایی، پرتغالی و اسپانیایی را فهرست می‌کنند؛ **پشتیبانی از بسته خاص Pocket Farsi v2 تأیید نشده است**. مدل‌های Pocket عمومی موجود در HayaiTTS نیز به‌خودی‌خود همان Pocket Farsi v2 نیستند.

### دستور توسعه بعدی برای TTS پالا
1. **اولویت اول:** آداپتور native و ایزوله Android برای Pocket Farsi v2 با بسته ONNX بالا، G2P فارسی، مدل صدای مرجع و پخش PCM محلی؛ معماری بدون Python runtime اجباری و بدون API خارجی؛ استفاده از native ORT/Android یا مسیر جایگزین تأییدشده. قبل از وعده قابلیت، prototype واقعی برای تمام گراف‌ها و G2P لازم است.
2. **حداقل منابع:** بارگذاری lazy فقط هنگام نیاز؛ عدم همزمان‌بودن دو مدل TTS؛ سنجش RAM هنگام حضور Qwen 4B در حافظه، تأخیر نخستین صوت، RTF، توقف و آزادسازی منابع؛ حفاظت از صفحه مکالمه. صرف وجود ۱۲ گیگابایت RAM تضمین همزیستی با Qwen نیست.
3. **اصل حفظ داده:** Gyro/HayaiTTS دست‌نخورده می‌ماند و **تا موفقیت آزمون Pocket روی همان تبلت، پیش‌فرض/گزینه بازگشت امن** است. انتخاب Pocket و دریافت ~۴۶۹MB بسته فقط با اقدام صاحب دستگاه؛ نصب/به‌روزرسانی خودکار، دانلود و تعویض صدا ممنوع. هیچ مدل جدیدی داخل build خودکار نرود.
4. **معیار قبولی:** پخش سه عبارت فارسی محاوره‌ای، یک متن بلند و عدد/تاریخ با صدای طبیعی در مقایسه A/B شنیداری با Gyro فعلی؛ اینترنت قطع؛ پاسخ Qwen واقعاً به Pocket داده و پخش شود؛ توقف/ادامه و پیشگیری از صفحه سفید؛ ثبت latency و Peak RAM روی Galaxy Tab S10 Ultra. قبولی code CI یا شنیدن نمونه انگلیسی Pocket معادل قبولی Farsi v2 نیست.
5. **محدوده فعلی:** هنوز هیچ آداپتور اجرایی Pocket Farsi v2 در PALA پیاده یا روی تبلت تأیید نشده است. شاخه توسعه و نسخه فعلی 0.3.3+6 نباید تا عبور از release gate و آزمون واقعی جایگزین شوند.

**از این پس اولویت بررسی TTS: Pocket Farsi v2 → مقایسه با Hayai/Gyro موجود → سایر موتورهای طبیعی در صورت عدم تحقق کیفیت/کارایی.** افزودن نمونه‌های بیشتر Piper هیچ امتیاز پیشرفت کیفی محسوب نمی‌شود.
