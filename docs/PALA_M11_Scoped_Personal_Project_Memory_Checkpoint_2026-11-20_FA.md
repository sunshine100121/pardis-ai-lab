## معماری پیاده‌سازی‌شده، بدون پایگاه‌داده موازی

- **حافظه عمومی:** جدول موجود `memories` در Drift/SQLite؛ حفظ شناسه، زمان، منبع و پین. گزینه‌های انقضای ۷، ۳۰، ۹۰ روز و بدون انقضا؛ اصلاح و حذف از همان صفحه Memory. موارد منقضی هنگام خواندن حافظه عمومی پاک‌سازی می‌شوند.
- **حافظه پروژه:** `ChatProject.memoryNotes` موجود و `ProjectMemoryGate`. یادداشت‌ها فقط با شناسه پروژه منطبق وارد Prompt می‌شوند. یادداشت تأییدشده می‌تواند در API موجود تاریخ انقضای اختیاری داشته باشد؛ `ProjectMemoryEntry.activeNotes` موارد منقضی را از فراخوانی و پاسخ حذف می‌کند، اما تاریخچه و متن ذخیره‌شده برای ویرایش/حذف مالک از بین نمی‌روند. یادداشت‌های قدیمی بدون تاریخ انقضا تغییر نمی‌کنند.
- **یادآوری مکالمه:** تاریخچه و شناسه گفت‌وگوی فعلی در سامانه اصلی چت. هیچ استخراج عمومی از گفت‌وگوی پروژه نامرتبط به حافظه عمومی صورت نمی‌گیرد؛ کد و آزمون قبلی جداسازی حفظ شدند.
- **حالت یادگیری:** خاموش/با تأیید/خودکار کم‌خطر در SharedPreferences تنظیمات (نه ذخیره‌گاه دوم خاطرات). تنها اظهار مستقیم کاربر که از فیلتر ایمنی عبور کند می‌تواند خودکار ثبت شود. برداشت مدل پیشنهاد است و وارد حافظه دائمی یا Prompt نمی‌شود مگر مالک آن را تأیید کند. پیشنهادها در UI قابل رد هستند؛ پیشنهاد تأییدنشده موقتی است.
- **رابط ساده:** در Settings > Memory انتخاب حالت یادگیری و نگهداری، پیشنهادهای قابل بررسی، اصلاح/حذف، و سبک پاسخ‌گویی رسمی/دوستانه/شوخ‌طبع. حالت «پیش‌فرض پالا» نیز برای حفظ لحن قبلی اضافه شده؛ هیچ تغییری به‌صورت اجباری اعمال نمی‌شود.
- **فارسی:** تشخیص محدود اما صریح ترجیحات، علاقه، نام، زبان و شغل فارسی، با رد جمله‌های فرضی، نقل‌قولی، منفی و موقتی. بازیابی پرسش‌های شخصی فارسی با یادداشت‌های مرتبط فراهم شد؛ ادعای فهم همه گویش‌ها و انواع بیان وجود ندارد.
- **سیاست حریم خصوصی:** اشتراک حافظه با Remote همچنان تابع مجوز قبلی خود است؛ اطلاعات حساس/حدسی ذخیره خودکار نمی‌شوند. یادداشت‌های تأییدشده بعد از بسته‌شدن برنامه باید از پایگاه‌داده قبلی بازخوانی شوند.

## محدودیت‌های آگاهانه
- هیچ مدل فعلی توانایی فهم بی‌خطای تمام جمله‌های فارسی و تشخیص قطعی واقعیت از حدس را ندارد؛ کد مسیر صریح را می‌پذیرد، موارد مبهم را برای تأیید پیشنهاد می‌دهد.
- تنظیم انقضای پیش‌فرض از این به بعد برای خاطرات عمومی جدید اعمال می‌شود؛ خاطرات عمومی قدیمی خودکار کوتاه نمی‌شوند.
- یادداشت دستی آزادِ پروژه از پیش باقی می‌ماند؛ انقضای پروژه به یادداشت‌های تأییدشده‌ای که با متادیتای انقضا ثبت شده‌اند اعمال می‌شود و هرگز بی‌مجوز تمام پروژه را پاک نمی‌کند.
- حافظه فعلی و شاخه اصلی به صورت موازی بازنویسی یا ادغام نشده‌اند.
